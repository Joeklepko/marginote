## 关于 Marginote

Marginote（取自 *marginal note*，页边批注）是一款本地优先的 Markdown 笔记 + 待办事项管理浏览器扩展。所有数据保存在你的浏览器本地，不上传任何服务器。

## 八、AI 优化

### 配置模型

支持多 provider 并存，单选激活。「测试当前模型」校验连通。

### 代理 URL

填在每个模型的「代理 URL」字段。两种格式自动识别，**仅作用于该模型的 endpoint host，其它流量不受影响**。

#### 模式 A：HTTP/HTTPS/SOCKS 代理（公司内网常用）

格式：`<scheme>://[user:pass@]host[:port]`

| 示例 | 说明 |
|------|------|
| `http://user:pass@corp-proxy.example.com:8080` | HTTP 代理含认证 |
| `http://corp-proxy.example.com:3128` | 无认证 |
| `https://proxy.example.com:8443` | HTTPS 代理 |
| `socks5://127.0.0.1:1080` | SOCKS5（如 v2ray/clash） |

效果等同于 shell 设置：

```
export http_proxy=http://user:pass@host:port
export https_proxy=http://user:pass@host:port
```

但区别：
- 仅扩展自动识别该模型 endpoint 域名 → 走代理
- 其他网页 / 浏览器流量保持 DIRECT
- 卸载扩展自动恢复系统代理

实现：扩展用 `chrome.proxy` API + PAC 脚本 + `webRequest.onAuthRequired` 注入认证。

#### 模式 B：URL 反代 / CORS 代理

URL 含路径 / 查询 / `{url}` 占位符 → 当 URL 重写处理：

| 示例 | 说明 |
|------|------|
| `https://corsproxy.io/?{url}` | `{url}` 替换为 URL 编码 endpoint |
| `https://my-proxy.example.com/` | 拼接为新基址 |

适用场景：自建反代、CORS 中转。

#### 留空 = 直连

#### 公司大模型部署示例

公司部署 deepseek-v3.1 在内网 `https://internal-deepseek.corp.com/v1/chat/completions`，必须走 `corp-proxy.corp.com:8080`，账户 `y00484287` 密码 `xxx`：

| 字段 | 值 |
|------|-----|
| Endpoint | `https://internal-deepseek.corp.com/v1/chat/completions` |
| 模型 ID | `deepseek-v3.1` |
| API Key | （后端要求的 key） |
| **代理 URL** | `http://y00484287:xxx@corp-proxy.corp.com:8080` |

保存后扩展自动应用代理规则，仅 `internal-deepseek.corp.com` 走代理。

> ⚠ 启用代理需 `proxy / webRequest / webRequestAuthProvider` 权限。Chrome 提示「Marginote 控制了你的代理设置」属正常现象，禁用所有 HTTP 代理或卸载扩展即恢复。

## 十四、常见问题

**Q: 卸载扩展数据会丢吗？**
会。请绑定本地文件夹同步，或定期 zip 备份。

**Q: 如何跨设备同步？**
方案 A：zip 导出 → 新设备导入。
方案 B：本地文件夹绑定到云盘（Dropbox / OneDrive / 坚果云）目录，多设备同步同一目录。

**Q: 图片占用大吗？**
图片以 base64 存 IndexedDB（不计入 5MB localStorage 上限）。绑定本地文件夹后图片以独立文件保存，不占浏览器空间。

**Q: AI 失败怎么办？**
数据·备份 modal 末尾「错误日志」查看详情。常见原因：API Key 错、网络问题、provider 限流、CORS 拒绝（试加代理 URL）。

**Q: 浏览器卡顿？**
笔记 > 1000 条时考虑导出归档老笔记。

**Q: 不想新标签页打开 Marginote？**
删 `manifest.json` 中 `chrome_url_overrides` 字段后重新加载扩展。

**Q: 如何固定扩展 ID？**
manifest 加 `"key": "<base64-pubkey>"`。详见扩展商店开发文档。
